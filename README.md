# Gema Hoang — Red Thread

Jewellery & metal design portfolio by Gema Phuong Hoang Chu.

Static website (HTML + CSS + JS, no build step). ES/EN switch and dark mode included.

## Structure

```
index.html      → the website
img/            → images used by the site
docs/           → portfolio PDF (16:9)
.nojekyll       → tells GitHub Pages to serve files as-is
```

## Publish with GitHub Pages

1. Create a new repository on GitHub (e.g. `gema-hoang`), public.
2. Upload all the files in this folder (drag & drop on "Add file → Upload files"), including `img/` and `docs/`.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/gema-hoang/`.

The PDF will be available at `https://<your-username>.github.io/gema-hoang/docs/Gema-Hoang-Chu-Portfolio-Red-Thread.pdf`.
